4 Core Architectural & Durability Guarantees

Engineered specifically for transparent, resilient Windows desktop synchronization

Production-Grade
🔒 TOCTOU-Safe Atomic Read

Holds active Windows handle with GENERIC_READ | FILE_SHARE_READ continuously during FastCDC stream chunking, preventing torn reads while apps write.

🔄 3-Tier Reconciliation Engine

Zero-loss guarantee: Cold startup scan, auto-recovery on Windows event buffer overflow, and periodic 15-second idle reconcile.

⚡ Cold-Start I/O Throttling

Runs with background I/O priority and micro-delays between chunks (10ms) to ensure desktop responsiveness even when processing 50,000+ files.

🏷️ Rename & Move Continuity

Detects file moves and renames on NTFS, maintaining object history continuity without re-hashing or storing duplicate chunk payloads.
